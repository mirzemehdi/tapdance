# Evidence: local iOS on a real Mac — 2026-11-01

Real devices and tools, no mocks. One machine (local mode). Recorded by the implementing agent while
building Tapdance; re-run with the commands below.

## Environment

| Item | Value |
| --- | --- |
| Host | MacBook Pro, Apple M1 Pro, 16 GB RAM, macOS 26.5 (arm64) |
| Xcode | 26.5 (17F42); runtimes iOS 18.5, iOS 26.5 |
| Node.js | 22.22.0 |
| Simlock | 0.4.0 (npm), standalone worker, `~/.simlock` |
| agent-device | 0.21.35 (bundled with Tapdance; Simlock runs it via `capabilities.agent-device.command`) |
| asc | 5.17.1 (Homebrew) |
| Device | iPhone 16 simulator, iOS 18.5, created by Simlock |

## What ran

1. **Spike (raw agent-device API through Simlock's proxy):** first lease 40 s (create + boot), warm
   lease 0.5 s, `open com.apple.Preferences`, 17-element interactive snapshot, `press label="General"`
   with settle diff, back, scroll, MP4 (6 MB), PNG, logs path, release.
2. **CLI:** `init --mode local`, `doctor` (correctly failed only on missing Android cmdline-tools),
   `device lease --platform ios --device "iPhone 16" --os 18.5`, `device status`, `app launch`,
   `ui inspect`, `ui tap --text General` (diff returned), `ui key back`, `ui swipe --direction up`,
   `screenshot`, `logs`, a second `device lease` refused with `LEASE_ALREADY_HELD` (exit 3),
   `record start` / `stop` (2.6 MB MP4), `artifacts`, `device release`; the detached keepalive
   (pid recorded) exited after release.
3. **MCP over stdio** (`packages/cli/src/mcp-local.integration.test.ts`, run twice, 70 s and 82 s):
   list tools (≥ 19), `lease_device`, `launch_app` (relaunch), `inspect_screen`, `start_recording`,
   `tap` by ref, `press_key back`, `wait_for stable`, `handle_alert get`, `swipe up`,
   `take_screenshot` (inline PNG > 1 KB and file on disk), `stop_recording` (MP4 > 10 KB),
   `get_logs`, `get_crash_logs`, `get_test_artifacts` (≥ 4), `list_tools`, `execute_tool asc
   --version` (exit 0, read-only), `release_device`, then `get_device_status` → `NO_ACTIVE_LEASE`.
4. **Browser viewer** (`tapdance view`, scripted as a browser would act): page served without auth;
   `/api/status` 401 before login; login with the fragment key → HttpOnly cookie; status shows the
   leased iPhone 16; `/stream` 200 with meta `{"codec":"h264","width":332,"height":720,"fps":30}`,
   one avcC description and a keyframe; `/input` WebSocket admitted (`0x83`) with screen config
   `{"width":1179,"height":2556}`; a touch from the "browser" set the human hold; the agent's next
   `ui tap` failed with `HUMAN_HELD`, `retryable: true`, `retryAfterMs` ≈ 6900.
5. **External tools:** `tapdance tools` (asc 5.17.1 and xcodebuild detected), `tapdance asc --
   --version`, `tapdance --json asc -- apps list --output json` (exit 0, output preserved).

6. **Custom app** (`examples/ios-demo`, built with `swiftc`): `app install` (upload + install),
   `app launch dev.tapdance.demo`, `ui inspect` (5 elements with identifiers), `ui type … --id email`,
   `ui type … --id password`, `ui tap --text "Sign in"` (diff: `+ @e5 [text] "Welcome, ada@example.com"`),
   `ui wait --text "Welcome, ada@example.com"` (26 ms), screenshot showing the welcome text, release.

## Re-run

```bash
pnpm install && pnpm build
tapdance worker install          # enables agent-device, stream, input on the local Simlock worker
TAPDANCE_IT_PLATFORM=ios TAPDANCE_IT_DEVICE="iPhone 16" TAPDANCE_IT_OS=18.5 pnpm test:integration
```
